# ארבעת המינים — מדריך תלת־ממדי אינטראקטיבי 🌿🍋

משחק לימודי בדפדפן (Three.js / WebGL) שמלמד **איך נוטלים את ארבעת המינים**, צעד אחר צעד, עם דמות תלת־ממדית בסוכה:

| פרק | מה לומדים ועושים |
|---|---|
| 1. הכרת המינים | אתרוג, לולב, הדס וערבה — מה מייחד כל אחד; זיהוי כשר ופסול; פיטם ועוקץ |
| 2. למה נוטלים | הציווי ("ושמחתם לפני ה'"), המדרש על ארבעה סוגי יהודים, המינים כנגד האיברים |
| 3. הרכבת האגד | שדרה אל המחזיק, בחירת ענפים כשרים, סידור לפי נוסח, גבהים, קשירה בטבעות |
| 4. אחיזה לפני הברכה | לולב בימין, אתרוג בשמאל, ולמה הפיטם **למטה** לפני הברכה |
| 5. הברכה | "על נטילת לולב", "שהחיינו", הסדר הנכון והפיכת האתרוג |
| 6. הנענועים | ששת הכיוונים לפי כל נוסח, ולמה (סוכה לז ב) — עם תרגול |
| 7. נענוע בהלל | איפה בדיוק מנענעים ב"הודו" וב"אנא ה' הושיעה נא" לפי הנוסח — כולל אתגר בזמן אמת |

**נוסחים/מנהגים:** אשכנז · ספרד (מנהג האר"י) · חב"ד — משפיעים על סידור האגד, סדר הכיוונים, ומקומות הנענוע בהלל.

## הרצה

פשוט לפתוח את `index.html` בדפדפן (הקובץ `dist/game.js` כבר בנוי ומצורף), או:

```bash
npm install
npm run build      # בונה את dist/game.js
npm start          # בונה ומגיש ב-http://localhost:8080
npm run dev        # בנייה בזמן אמת עם esbuild
```

## מבנה הקוד

- `src/models.js` — דגמים פרוצדורליים: לולב, הדס, ערבה, אתרוג, אגד, דמות עם זרועות (IK דו־עצמות)
- `src/world.js` — סוכה, שולחן, מצלמה, נענועים, סימני כיוון
- `src/content.js` — נוסחים, תוכן לימודי, ברכות, בניית שורות ההלל
- `src/chapters.js` — הפרקים והמשימות
- `src/game.js` — מנוע השלבים, ניקוד וכוכבים, רכיבי שאלות
- `src/audio.js` — צלילים והקראה (אופציונלי)

## הערה

המשחק נועד ללימוד. בשאלות הלכה למעשה יש לפנות לרב או למורה הוראה ולנהוג לפי מנהג הקהילה — יש שוני בין קהילות בפרטים רבים (סידור ההדסים והערבות, מספר הנענועים ועוד).
